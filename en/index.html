Find avatar problems before the upload screen.

Avatar Refinery Lite checks a VRChat avatar inside Unity and explains what it found, why it matters, and what to do next. The diagnostic pass is read-only: it does not change your avatar or assets.

Choose an avatar root and run the check. Findings are grouped by urgency, with plain-English guidance and an optional Markdown report.

Upload blockers

Spot missing Avatar Descriptors, rig and Animator issues, broken Expression references, Missing Scripts, and other common setup problems.

Materials and performance

Install for free

Recommended environment: Unity 2022.3.22f1 and VRChat SDK - Avatars 3.9.x–3.10.x (tested with SDK 3.10.4). Use either installation route below; both provide the same Lite tool.

Please read the Japanese and English terms of use before installing.

Recommended: VCC or ALCOM

  1. Open your VRChat avatar project in VCC or ALCOM.
  2. Add the Avatar Refinery repository and approve the prompt.
  3. In your project's package manager, install Avatar Refinery Lite.

If the button does not open VCC or ALCOM, choose Settings → Packages → Add Repository and paste this URL:

https://tmiosg-commits.github.io/avatar-refinery/vpm.json

Manual: unitypackage

Download Avatar Refinery Lite v0.3.1 directly from this GitHub-hosted site.

  1. Open your Unity project.
  2. Import the downloaded .unitypackage.
  3. Wait for Unity to finish compiling.

VCC / ALCOM is recommended if you want package updates through the manager.

Run your first check

  1. In Unity, open Tools → Avatar Refinery → Open Avatar Refinery.
  2. Select your avatar's root object in the Hierarchy.
  3. Choose English or Auto, then click Check Avatar.
  4. Review the findings. Use Save Report to export a Markdown report if you need help or want to keep a record.

The PC and Quest grades are local estimates; VRChat determines the final grade. Lite diagnoses and explains issues but does not automatically fix them or convert an avatar for Quest.

Want guided fixes too?

Avatar Refinery Pro adds previews, automatic backups, before-and-after checks, and guided fixes for a limited set of supported issues. Lite remains free and usable on its own. Pro does not perform Quest polygon reduction, material merging, or mobile shader conversion.
